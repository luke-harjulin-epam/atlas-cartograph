        Atlases

        Open Atlases share one graph. Add another store, or remove one from this view without deleting its files. At least one Atlas stays open.

        Layout

        Layers groups pages by type and schema. Atlases groups by store. Proximity uses folder and relationship neighborhoods.

        Layout changes placement, not relationships or schema membership. Use View in the status bar to focus a group.

        Layers

        When all layers are selected, choose a schema or type to select only it. Then select more layers to add them, or select an enabled layer to remove it. Removing the last selection restores all layers.

        All restores node layers without changing link visibility. Newly discovered types start visible. Core comes from SCHEMA.json; contributions come from schema.d. A dashed schema button means some of its types are visible. Counts include every declared type, even when empty.

        Other pages

        Pages outside declared schema types remain available here, including legacy categories, navigation indexes and untyped pages. Undeclared types have an explicit type that no loaded schema declares.

        These categories describe page metadata, not folder ownership. Expanding Other pages does not change visibility.

        Links

        Relates shows relationships between pages. Provenance shows source links within the graph. Both controls change edge visibility without hiding nodes or creating relationships.
